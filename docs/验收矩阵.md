# 第一版验收矩阵

## 验收原则

- 同一输入在页面纯逻辑与新核心中得到相同结果；
- 数学合法、框架兼容、理论容量和实测结果分别表达；
- 非法配置必须返回规则编号、相关字段和公式；
- 修复建议不得修改锁定字段；
- 理论容量必须返回假设和置信等级。
