## 每次答复的记录格式

在本文件末尾按“场景 N · 样本 A/B · 日期时间”追加一条记录，不覆盖旧答复。记录用户原话和 Agent 最终答复的完整文本或其仓内链接，并填写：

| 字段 | 记录内容 |
| --- | --- |
| 输入版本 | 主配置与模型结构的路径、磁盘字节 SHA-256；若使用副本，另记修改前后摘要及差异。 |
| MCP 调用 | 实际调用的工具、`parse_training_config.data.mcp_invocation.request_id`、各工具状态；本地回退要单独标记。 |
| 验收答复 | 用户原话、Agent 最终答复、候选数量、依据与未覆盖范围；不要只贴工具 JSON。 |
| 结果 | 通过 / 未通过 / 条件不足，以及对应证据、缺陷、待补信息和下一次复查动作。 |

场景 2、3 如需修改配置，只修改从原件复制出的源文件，并在答复中给出可审阅的文件差异。容量只能按工具结果标为 `theoretical`、`model-informed` 或 `calibrated`；性能收益和训练可运行性以目标环境实测为准。
