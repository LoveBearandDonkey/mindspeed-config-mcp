# 第一版能力源码映射

## 原则

- 页面仓库提供当前产品行为基线；
- MindSpeed Core 和匹配的 Megatron-Core 提供框架语义证据；
- 新项目只保留纯计算实现，不复制 DOM、SVG、事件监听或训练运行时；
- 每条规则进入规则包时记录上游仓库、Commit、文件、函数或行号；
- 页面规则与框架规则不一致时输出差异，不静默选择其中一方。

## 1. `validate_parallel_config`

| 来源 | 位置 | 提取内容 |
| --- | --- | --- |
| 页面共享规则 | `shared/plane-rules.js:160-241` | world size、DP/EP 口径、EP 域和基础整除关系 |
| 页面控制器 | `config-relation-observer.js:1519` | 完整静态校验与错误字段 |
| 页面控制器 | `config-relation-observer.js:1645` | 非阻塞告警 |
| MindSpeed Core | `mindspeed/arguments.py:719-734` | PP/VPP 与层数关系 |
| MindSpeed Core | `mindspeed/arguments.py:770-828` | 专家数、TP、EP 相关约束 |
| MindSpeed Core | `mindspeed/arguments.py:869-953` | Ulysses、Ring、Hybrid 等 CP 约束 |

第一版结果需要区分：

- `page-rule`：页面当前已经实现的数学约束；
- `mindspeed-rule`：指定 MindSpeed 版本中可追溯的框架约束；
- `compatibility-gap`：框架存在但页面尚未建模的约束。

## 3. `suggest_config_fixes`

| 来源 | 位置 | 提取内容 |
| --- | --- | --- |
| 页面控制器 | `config-relation-observer.js:1830` | 围绕锚点字段配平配置 |
| 页面控制器 | `config-relation-observer.js:2250` | 不直接修改原配置的候选修复 |

抽取时必须增加以下契约：

- 输入明确列出 `locked_fields`；
- 输出是差异列表，不原地修改调用方对象；
- 每项修改包含旧值、新值、触发规则和取舍说明；
- 找不到兼容方案时返回结构化失败，不返回未经验证的近似值。

## 4. `parse_training_config`

| 来源 | 位置 | 提取内容 |
| --- | --- | --- |
| 页面导入模块 | `config-relation-import.js` | YAML、Shell 和 JSON 的字段识别思路与页面字段命名 |
| 统一输入契约 | `parse-training-config-v1.schema.json` | 显式传入内容、格式、框架、版本和来源文件名 |
| 当前实现 | `parse-training-config.js` | 字段映射、类型转换、缺失字段、未识别字段和忽略字段 |

第一版只解析调用方显式提交的文本，不根据文件路径读取服务器文件；未登记的字段必须
进入 `unmapped_fields`，不能静默忽略。

| 来源 | 位置 | 提取内容 |
| --- | --- | --- |
| 页面容量模块 | `config-relation-capacity.js:114` | 激活系数 |

| 页面容量模块 | `config-relation-capacity.js:869` | 只读 `measureAll` 入口 |
| MindSpeed Agent | `llm-model-analysis` | 按需从真实模型补齐结构与参数量，不作为第一版必需输入 |
| MindSpeed Agent | `fsdp2-model-analysis` | 按需补充 FSDP2 切分和通信估算 |

容量结果必须标记为：

- `theoretical`：只使用页面表单和经验系数；
- `model-informed`：补充了 `config.json` 或真实模型结构；
- `calibrated`：使用短训练或 Profiling 数据校准。

## 不进入第一版纯计算核心的文件

- `config-relation-plane.html`：页面壳和展示；
- `config-relation-plane.js`：DOM/SVG 绘制；
- `config-relation-doc.js`：页面说明内容；
- `config-relation-yaml.js`：配置生成属于分析表第 5 项，不在第一版范围；
- `config-relation-import.js` 的 DOM、文件选择和页面回填逻辑：第一版只借鉴字段映射，
  不整体复制浏览器控制器；
- 完整 MindSpeed Python 包：第一版服务端不导入训练运行时。
