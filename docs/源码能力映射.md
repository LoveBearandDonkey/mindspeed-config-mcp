# 第一版能力源码映射

## 原则

- 页面仓库提供当前产品行为基线；
- MindSpeed Core 和匹配的 Megatron-Core 提供框架语义证据；
- 新项目只保留纯计算实现，不复制 DOM、SVG、事件监听或训练运行时；
- 每条规则进入规则包时记录上游仓库、Commit、文件、函数或行号；
- 页面规则与框架规则不一致时输出差异，不静默选择其中一方。

- `compatibility-gap`：框架存在但页面尚未建模的约束。

| MindSpeed Adaptive Recompute | [`docs/features/adaptive-recompute.md`](https://gitee.com/ascend/MindSpeed/blob/f82a6dd5a4b4146f387d02b2ffea1b8da58e0afb/docs/features/adaptive-recompute.md) | 官方自适应重计算依赖运行时 Profiling；静态评分只复用理论容量口径并显式降级置信度 |

抽取时必须增加以下契约：

- 输入明确列出 `locked_fields`；
- 输出是差异列表，不原地修改调用方对象；
- 每项修改包含旧值、新值、触发规则和取舍说明；
- 找不到兼容方案时返回结构化失败，不返回未经验证的近似值。

## 4. `parse_training_config`

| 来源 | 位置 | 提取内容 |
| --- | --- | --- |
| 页面导入模块 | `config-relation-import.js:162-233` | Shell 标量变量、`${VAR:-default}`、`WORLD_SIZE` 与注释处理 |
| 页面导入模块 | `config-relation-import.js:249-503` | MindFormers、Megatron、HF、LLaMA-Factory、DeepSpeed 的键名与保守推导口径 |
| 页面测试语料说明 | `config-test/README.md:3-30` | 11 份样本分别覆盖模型结构、训练配方、并行启动和分片配置；不把它们假定为可任意拼接的一套配置 |
| 统一输入契约 | `parse-training-config-v1.schema.json` | 显式传入内容、格式、框架、版本和来源文件名 |
| 当前实现 | `parse-training-config.js` | 字段映射、类型转换、缺失字段、未识别字段和忽略字段 |
| 解析格式诊断 | `parse-training-config.js@0.2.1` | YAML、JSON 或 Shell 语法无法解析时明确标记“输入格式不合法”，并保留底层解析器错误细节 |
| DeepSeek-V3 模型证据 | `config-test/hf_deepseekv3_config.json`、`config-test/mf_pretrain_deepseek3_671b.yaml` | 缺失结构常量、MindFormers offset 与补齐候选；候选必须经过 `validate_parallel_config` 复验 |
| 当前补齐核心 | `plan-training-config-completion.js` | 每次解析时按当前源配置和模型证据即时求解候选、标注置信度，并返回经过完整静态复验的可选方案；常规四字段搜索无解时，按 `validate-parallel-config.js` 已建模约束生成静态安全兜底，把缺失项和冲突改值逐项交给用户审核；不按预置名称保存答案 |

第一版只解析调用方显式提交的文本，不根据文件路径读取服务器文件；未登记的字段必须
进入 `unmapped_fields`，不能静默忽略。Shell 解析只展开文件内的安全标量和常见乘法，
不执行脚本。`mapping_kind=default` 与 `mapping_kind=derived` 必须区别于原文显式字段；
硬件型号、物理显存和没有证据的跨文件字段不得伪装成源文件事实；工作台需要形成完整候选时，
只能以可编辑的显式假设补齐，并在应用前对整个候选重新校验。

容量结果必须标记为：

- `theoretical`：只使用页面表单和经验系数；
- `model-informed`：补充了 `config.json` 或真实模型结构；
- `calibrated`：使用短训练或 Profiling 数据校准。

## 不进入第一版纯计算核心的文件

- `config-relation-plane.html`：页面壳和展示；
- `config-relation-plane.js`：DOM/SVG 绘制；
- `config-relation-doc.js`：页面说明内容；
- `config-relation-yaml.js`：配置生成属于分析表第 5 项，不在第一版范围；
- `config-relation-import.js` 的 DOM、文件选择和页面回填逻辑：第一版只借鉴字段映射，
  不整体复制浏览器控制器；
- 完整 MindSpeed Python 包：第一版服务端不导入训练运行时。
